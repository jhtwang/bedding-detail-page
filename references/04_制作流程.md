# 04 制作流程（标准作业）

资料预填 → 素材准备 → 信息确认 → 文案定稿 → LibTV分模块出图 → 审图迭代 → 拼版合成 → 合规终审 → 切片交付 → 上架

## 前置步骤：资料预填（Codex，2026-08-27 定稿）
> **触发词**：商家说「填表 / 填一下表 / 生成表格 / 资料预填」等，即执行本前置步骤

1. 商家给产品文件夹，**文件夹名 = 品名**（如 `乐优家 春山在望 森语棉麻床品四件套`）
2. Codex 按品名到 `Y:\AI资料库\` 读取该产品信息（**该文件夹只读，禁止修改**）
3. 调用素材清单模板（`详情页规则库\素材清单模板\四件套详情页素材清单_模板.xlsx`），用读到的产品资料**自动填写**（①基本信息/材质工艺/规格等）
4. 填写完成后保存到商家给的产品文件夹（命名如 `四件套详情页素材清单_<品名>.xlsx`）
5. **交商家审核 + 填写图片信息**（③表指定图片等）
6. 商家确认后，再进入下方 阶段0 正常流程

## 阶段0：素材准备（商家）
1. 新建产品文件夹：`品牌_款名_品类`
2. 放全部实拍图（各角度/细节/透明图/白底图，不用筛选改名）
3. 复制素材清单模板并填写（`详情页规则库\素材清单模板\`）

## 阶段1：信息确认（协同）
- 读表 + 图片分类
- 读「③表指定图片」列：仅 首屏/卖点1-3/细节图1-4/场景 可指定（指定了用指定文件，未指定按默认流程自动选图）；其余图片按原规则自动处理
- 缺失必填项列清单：支数/成分/安全类别/执行标准/一句话卖点/卖点1-3；品牌理念为核对项（①第4项已确认，从品牌资料库自动读取）
- 品牌资料：从品牌资料库自动读取（LOGO/理念/模板）
- 透明图准备：确认卖点1/2/3 用图——已有透明PNG直接选用；不足的由 Codex 用 rembg（u2net）从实拍图抠图；抠图后核对边缘干净、产品完整、三张不同角度（正面/侧面/近景），以 alpha 像素分析为准
- 素材缺失兜底：铺床图/细节图/场景图/透明图不足时，按 05_工具与素材规范「素材缺失兜底」处理

## 阶段2：文案定稿（Codex）
- 按9模块写文案，过03合规边界
- 产出：每模块最终文案 + 用图清单

## 阶段3：LibTV分模块出图（Codex执行，商家审核）
- 需要AI出图的模块：首屏、卖点1/2/3、细节实拍、规格材质、洗涤护理（共7个）；**场景大图不走LibTV**（本地实拍直接做，优先3:4大主图）
- **品牌理念、底部备注模块不走LibTV**（均用定稿模板直接复用）
- **文案由 LibTV 随图一起生成**：正式标题/卖点写进提示词（首屏标题取①第2项「商品标题/产品名称」，首屏卖点取①第24项、卖点1-3取①第25-27项），不整体后贴
- 固定组合：模型 **Lib Image 2.5 Pro** + 模板「一键电商爆款产品详情页长图整套全案设计」+ 统一风格前缀（ratio=3:4 / quality=high / resolution=2K）
- 每模块：1张参考图 + 1条提示词（细节模块例外：需4张参考图，可拼成一张2×2合成图作为单参考图）
- 下载必须 `--without-ai-watermark --vip`
- 商家逐张审核：满意 / 重跑 / 换图

## 阶段4：拼版合成（Codex）
- 9模块按顺序拼接 → 1440px宽长图
- 首屏：直接用 LibTV 生成的主视觉（含正式标题+卖点文案），不再用 Pillow 叠加文字
- 品牌理念、底部备注模块直接用定稿模板，不生成AI版、不重排
- **AI 文案直接使用**：卖点1-3、细节实拍、规格材质、洗涤护理直接使用 LibTV 生成图（含 AI 文字），不做 Pillow 后贴/修正（AI 字体问题不处理）；场景大图用本地实拍，仅场景底部提示字由 Pillow 添加
- 场景大图：③表指定了用指定场景图，未指定用 CLIP 自动挑选实拍场景图；**统一调成 3:4（1440×1920）：等比缩放+居中裁剪/补边，禁止拉伸变形**，Pillow 加底部小字「场景实拍｜非卖品仅为搭配展示」
- 页面底部固定免责备注：直接调用 `品牌资料库\详情页模板\底部备注模块_四件套.png`（固定1440×720），不得用 Pillow 重新生成；模板已固定测量误差1-3cm、颜色以实物为准、纯四件套不含枕芯被芯
- **拼版完成后先输出整页预览给商家确认**，满意再进入阶段5；需调整在此迭代
- 切片（**按模块切**：一个模块一张 JPG 切片；如平台限高≤960px，再在模块内拆分；不交付 PNG）

## 阶段5：合规终审
- 03合规边界自查表逐项过
- 数据出处核对（质检报告编号）
- 页面底部免责备注、场景「非卖品仅为搭配展示」已写全

## 阶段6：交付上架（商家）
- 上传切片到图文详情
- 同一款多规格共用一个详情页（规格对照表覆盖，②表加行即可），无需重复流程
- 不同款 / 不同链接：才按同样流程复制

## 固定约定
- 一表一款产品；多规格在②表加行（同一详情页规格对照表覆盖）
- AI图只做版式底版，产品本体用实拍
- AI 文案由 LibTV 随图生成、直接使用（AI 字体问题不处理）；场景底部提示字用 Pillow，页面底部免责备注直接调用四件套定稿模板
- 批量生成前先确认（消耗LibTV额度）

## 类目适配
- 本流程以四件套为基准；新类目（枕头/被芯等）先完成：①类目素材清单 ②类目详情页排版，再按本流程执行
